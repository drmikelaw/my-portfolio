Estimating Project Resources

A 5:48 whiteboard-animation lesson built for LT 8150, Project Management for Instructional Designers, in the Georgia State University M.S. Instructional Design & Technology program. It walks through three segments: bottom-up resource estimating, rolling work packages up into a project total, and converting effort into calendar duration.

How it was made

Another sandbox project: a repeatable pipeline for course videos where every scene is a small configuration file, so a corrected number or reworded line is a quick edit and a re-render.

Whiteboard engine

  • Custom engine in HTML, SVG, and JavaScript with GSAP timelines
  • Hand-drawn doodle library (clipboards, calendars, hourglasses, magnifiers) drawn stroke by stroke by an animated marker

Render & assembly

  • Deterministic frame-by-frame rendering in headless Chromium
  • FFmpeg for encoding, segment joins, and a 2-second dissolve, with audio kept in sync across every cut

Splash & sound

  • Reusable 4-second branded splash with fly-in type, screen shake, and particle bursts; the course name is one line of config
  • Python (NumPy/SciPy) for synthesized music and sound effects timed to each hit

Timing

  • Narration aligned to the drawings by audio analysis, so each number and label appears as it is spoken

The process

  1. Define the learning goal and the three-segment structure.
  2. Script each scene with example numbers a student can follow.
  3. Configure each scene and draw its doodles with the whiteboard engine.
  4. Time the drawings to the narration, then render and review frame by frame.
  5. Assemble the branded splash, segment slides, and lessons into one master.
  6. Review, fix, and re-render with a human making every instructional and editorial call.
In short: a one-command rebuild from idea to polished, brand-consistent course video, with the same framework reusable across courses.
